# 01 · Identificação

- **Pré-requisitos:** nenhum (é a primeira área)
- **Destino:** `00_ENTRADAS` · seção IDENTIFICAÇÃO · coluna `D`, linhas 10–23 (campos F01–F14)
- **Alimenta:** `01_PAINEL`, `02_ABERTURA`, `03_ESCOPO`, `07_GANTT`, `15_ENCERRAMENTO`
- **Como preencher:** escreva o valor logo abaixo de cada campo. Deixe em branco o que ainda não souber — a planilha aceita campos vazios até a aprovação. Textos longos podem usar várias linhas.

### F01 · Código do projeto
> Ex.: GP-001 • identificador único


### F02 · Nome do projeto
> Nome oficial e legível


### F03 · Versão do documento
> Ex.: 1.0


### F04 · Organização / unidade
> Área, equipe ou empresa


### F05 · Patrocinador
> Responsável pela autorização


### F06 · Gerente de projeto
> Pessoa designada


### F07 · Autoridade do gerente
> Limites e alçadas de decisão


### F08 · Status geral
> Planejamento / Em execução / Suspenso / Encerrado
> Valores permitidos: Planejamento / Em execução / Suspenso / Encerrado


### F09 · Prioridade
> Alta / Média / Baixa
> Valores permitidos: Alta / Média / Baixa


### F10 · Abordagem
> Preditiva / Híbrida / Adaptativa
> Valores permitidos: Preditiva / Híbrida / Adaptativa


### F11 · Início previsto
> Data inicial aprovada
> Formato: data (DD/MM/AAAA)


### F12 · Término previsto
> Data final aprovada
> Formato: data (DD/MM/AAAA)


### F13 · Emissão do termo
> Data da versão de abertura
> Formato: data (DD/MM/AAAA)


### F14 · Data de aprovação
> Data do aceite do patrocinador
> Formato: data (DD/MM/AAAA)
